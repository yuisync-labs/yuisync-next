## Gated phase

### WA6 — Coexistence History Sync

**GATE MERGED IN PR #54; PROVIDER-SPECIFIC HISTORY IMPLEMENTATION REMAINS BLOCKED.**

`docs/architecture/ADR-WHATSAPP-COEXISTENCE-HISTORY.md` is the source of truth for unlocking this phase.

Required before code may import historical messages:

1. current official Meta documentation must explicitly describe the coexistence/history event or supported history-sync mechanism;
2. a real payload from the configured Meta App/number must be captured;
3. the payload must be sanitized and committed as a fixture with secrets, phone numbers, customer content and IDs anonymized;
4. the ADR must be updated with the official source, observed fixture, replay/idempotency semantics and retention/window assumptions;
5. tests must prove `historical message != live incoming customer message` and that history can never trigger Luna, automations, notifications or operational side effects.

The official Meta material verified so far supports Embedded Signup, WABA subscription, message sending and status tracking, but the sources reviewed still do not provide enough verified detail to safely promote a provider-specific legacy coexistence-history parser into Next.

### Launch interpretation

WA6 history sync is not a launch blocker unless synchronized historical coexistence messages are explicitly required for the first production release. Live inbound, tenant-scoped outbound, Embedded Signup, WABA subscription, templates and delivery-status reconciliation are separate from that gated history capability.

Therefore the repository can be considered internally prepared for the WhatsApp production cutover after PR #55 is merged and its final CI head is green. The remaining work is external configuration/verification with the real Cloudflare production resources and the Meta app/number.

Rollback is the reverse routing operation: restore the recorded previous Meta callback/Cloudflare target while leaving normalized D1 records intact for diagnosis. Do not roll back by deleting production message history.
